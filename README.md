# 智能台账助手隐私政策

科研院智能台账助手（aTrust版）的独立隐私政策网站，适用版本 1.3.0。

- 发布内容：index.html 与 .nojekyll。
- 托管方式：GitHub Pages，main 分支的仓库根目录。
- 联系邮箱：qinweirz@qq.com。
- 无依赖、无构建步骤、无统计脚本。
- 此仓库不包含插件源代码、.env、登录凭证或业务记录。

## 本地预览

在本目录运行 `python3 -m http.server 8088`，打开 http://localhost:8088/。

## 更新

插件行为变化时，应同步更新 index.html 中的政策正文、版本和生效日期。
